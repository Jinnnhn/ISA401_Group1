# ISA401_Group1
ISA401_group HAI project

# SpaceMate 第一阶段交互验证

技术栈：Vue 3、TypeScript、Vite、Three.js、Pinia。使用 Node.js 22.12 或更新的兼容 LTS 版本。

## 运行

在本目录打开终端：

```powershell
npm.cmd install
npm.cmd run dev
```

打开终端输出的本地网址。检查命令：`npm.cmd test` 和 `npm.cmd run build`。

## 本次范围

可旋转缩放的客厅视角、三件简单立体家具、鼠标拖动、网格吸附、单件自动让位、锁定、Esc 取消和整次撤销。
仅计算二维地面占地，没有物理引擎、AI 或评分。旋转与卧室留到下个阶段。

## 请按顺序验收

1. 将沙发拖到茶几附近：茶几寻找最近的有效网格位置，平滑让位。
2. 松手，再点击撤销：沙发和茶几同时回到原来的位置。
3. 再次拖动，按 Esc：取消整个预览，不产生历史记录。
4. 在右侧选择茶几并锁定，再拖动沙发靠近：茶几不动，提示锁定冲突。
5. 将家具拖出房间并松手：不提交越界位置。
6. 锁定沙发，尝试拖动：位置保持不变。

程序从拖动开始的快照计算候选，不连续推挤多件家具。同一输入以距离和坐标排序，保持结果确定。

## 三人接下来怎么推进

- A：按以上步骤验收 3D 与拖动，记录遮挡、落点和动画问题。
- B：验证锁定、让位和撤销规则，补充失败场景。
- C：访谈 3–5 位有搬家经历的同学，记录是否理解让位行为及需要的反馈。

完成本阶段后再添加 90° 旋转、卧室与 AI 建议，不同时扩展所有功能。

## 文件分工

- `src/layout.ts`：纯布局规则，可独立测试。
- `src/store.ts`：已提交状态、选择、锁定与撤销历史。
- `src/App.vue`：界面和 Three.js 渲染，动画不逐帧写入 Pinia。
- `src/layout.test.ts`：边界、锁定、确定性与单件让位测试。

## 视角操作

- 鼠标右键拖动：围绕房间旋转视角，限制俯仰以避免钻入地面。
- 滚轮或中键拖动：缩放，限制最远和最近距离。
- 左键拖动：仅移动家具；移动期间暂停相机操作。
- 点击“复位视角”：恢复初始相机位置，不改变家具或撤销历史。
- 本阶段面向桌面鼠标操作，不提供触屏视角手势。

验收：从不同角度拖动并撤销家具，确认视角变化不影响落点判断；拖家具时滚轮不改变视角；复位只影响相机。
